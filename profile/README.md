## 🚀 What we do

EcomPHP builds lightweight, developer-friendly PHP SDKs for leading e-commerce
platforms. Our open-source libraries make it easier to connect PHP, Laravel, and
Symfony applications to marketplace APIs with clean, maintainable integrations.
